# kazlang_app

Flutter-клиент для проекта `LanguageLearning`.

Это не финальная версия приложения, а текущая рабочая стадия разработки.

## Что уже есть

- авторизация и регистрация
- экран уроков
- экран слов
- экран прогресса пользователя
- базовая работа с учебным контентом
- воспроизведение аудио для уроков и слов
- TTS-озвучка слова, если отдельное аудио не задано

## Запуск

```powershell
flutter pub get
flutter run
```

## Примечание

Если backend доступен по другому адресу, базовый URL API можно изменить внутри приложения.
